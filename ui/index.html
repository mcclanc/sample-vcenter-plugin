Tanzu Platform

Hub Deployment Types

Plus supported capabilities

POC Appliance

Functionality:

  • Designed for specific use case for evaluation only.
  • Single appliance
  • 90 day license included for evaluation.
  • No HA / DR
See POC Guide

VSI / TSE Deployment (Appliance)

Functionality:

  • Designed for small environments:
    • 10 connected Kubernetes clusters for VMware Secure Image service.
  • Single appliance
  • Requires license key
  • DR capability based on backup and restore.
  • No HA available

Full Enterprise Deployment

Functionality:

  • Designed for full Tanzu Platform functionality
  • Requires license key
  • DR capability available through active / passive
  • HA available through multi-AZ deployment
  • Comes in multiple resource sizes based on need. (See sizing guide)

Not sure? Start with the POC Appliance — it includes a 90-day license and deploys in minutes.
