Connect this vCenter to Tanzu Hub

Registers this vCenter as a Management Endpoint in Tanzu Hub via the upsertEndpointWithCredential GraphQL mutation. Fill in the fields below and click Connect — the endpoint and its credential will be created (or updated if one with the same name already exists). See Connect and manage VCF instances for background.

Use the FQDN or IP that Tanzu Hub can reach (TLS on port 443). If selected, the vCenter user must have read/write permissions; otherwise read-only is enough for inventory collection.
Click the button to retrieve the certificate automatically, or paste a PEM manually.
Tanzu Hub connection The GraphQL endpoint for your Tanzu Hub instance. Sent as Authorization: Bearer <token>.
